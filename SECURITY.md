# Security

## Supported version

Security and privacy fixes apply to the latest version on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature when it is available for this repository. Do not include Peacock credentials, session data, or other personal information in a report.

## Security boundary

Peacock Skip for Safari intentionally has no server component, analytics integration, account system, or remotely loaded code. Its Safari permissions are limited to local extension storage and Peacock pages.
