# Privacy Policy

Peacock Skip for Safari is designed to work without collecting user data.

## Data stored on the Mac

The extension stores four Boolean preferences in Safari's local extension storage:

- Skip intros
- Skip recaps
- Play the next episode
- Skip detected ads

The extension does not store viewing history, page content, video titles, account information, authentication information, location, or advertising identifiers.

## Data processed during playback

On `peacocktv.com`, the extension temporarily reads specific page controls, visible ad countdown text, and the current HTML video position. It uses that information immediately to click a playback control or seek the video. The extension does not save or transmit that information.

## Network activity

The extension does not initiate analytics, telemetry, tracking, remote-configuration, account, or other service requests. Peacock itself continues to make the network requests required for its website and video service. Selecting the Peacock icon in the extension popup opens Peacock's website at the user's request.

## Data sharing and retention

The extension does not sell, share, or transfer data because it does not collect data. Local preferences remain on the Mac until the user changes them, clears Safari extension storage, or removes the extension.

## Permission scope

The extension requests local storage and access to `*.peacocktv.com`. It does not request access to other websites.

## Changes

Any future feature that changes this data boundary must update this policy before release.
